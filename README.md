# Student Management System (Java)

A console-based Java application designed to manage student records using Object-Oriented Programming concepts.

## Features
- Add student details (ID, Name, CGPA)
- View all student records
- Sort students by CGPA (High to Low)
- Menu-driven console interface

## Technologies Used
- Java
- Git & GitHub

## Concepts Implemented
- Object-Oriented Programming (Classes, Objects, Encapsulation)
- ArrayList for dynamic data storage
- Comparator and sorting using Java Collections
- User input handling using Scanner

## Project Structure
- Main.java – Handles user interaction and application flow
- Student.java – Represents the student model with attributes and methods

## How to Run
1. Compile the program:
javac Main.java Student.java

2. Run the application:
java Main
